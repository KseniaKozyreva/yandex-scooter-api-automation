# Проект по автоматизации тестирования сервиса "Яндекс.Самокат"

Этот проект содержит автотесты на Python для проверки ключевого функционала сервиса "Яндекс.Самокат".

# Структура проекта
locators/ — файлы с локаторами элементов страниц (разделены: Header, Home, Registration, Base).
pages— Page Object классы с описанием логики взаимодействия с элементами.
tests/— тестовые сценарии 
conftest.py — конфигурация Pytest и фикстуры для запуска браузера (используется Firefox).

# Тестовые сценарии
1. Проверка всех 8 вопросов и ответов на главной странице.
2. Позитивный сценарий оформления заказа с двумя наборами данных (Иван и Пётр)
3. Проверка перехода на главную при клике на лого "Самокат" и перехода в "Дзен" при клике на лого "Яндекс".
4. Валидация: Проверка появления ошибок при пустых полях формы заказа.

Как запустить тесты
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest -v`

# Отчёты
Для генерации и просмотра Allure-отчёта:

1. Запустить тесты и собрать данные:

   pytest --alluredir=allure_results
    

2. Сгенерировать статический отчет:

    allure generate allure_results -o allure-report --clean

3. Открыть готовый отчет:

    allure open allure-report
