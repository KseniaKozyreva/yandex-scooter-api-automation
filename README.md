### Автоматизация API и настройка CI/CD пайплайнов для Яндекс Самокат 🛴

Проект представляет собой автоматизированный комплекс для тестирования REST API сервиса «Яндекс Самокат» с интегрированной настройкой непрерывной интеграции (**CI/CD**). 

Тестирование реализовано на **Python** (pytest + requests). Настроен автоматический запуск пакета тестов в облачной инфраструктуре при каждом обновлении кода. 

### 🛠️ Технологический стек и инструменты

* **Язык программирования:** Python 3.10+
* **Тестирование REST API:** Requests, PyTest
* **Инструменты CI/CD:** GitHub Actions (автоматический запуск тестов в облаке)
* **Отчетность:** Allure Framework

### 📂 Архитектура проекта

* .github/workflows/ — конфигурационные файлы пайплайнов непрерывной интеграции.
* locators/ / pages/ — базовая структура проекта.
* tests/ — тестовые сценарии для сквозной проверки API.
* conftest.py — глобальная конфигурация PyTest и управление фикстурами.

### 📈 Ключевые итоги работы

* **Внедрение CI/CD процессов:** Спроектировала и настроила автоматический пайплайн непрерывной интеграции (**CI**) на базе **GitHub Actions**, обеспечивающий автоматический прогон тестов на удаленном сервере при каждом пуше.
* **Автоматизация инфраструктуры отчетов:** Интегрировала сбор Allure-результатов напрямую в облачный пайплайн для прозрачного мониторинга стабильности билдов.
* **Покрытие негативных сценариев:** Покрыла автотестами валидацию полей ввода и появление системных ошибок при отправке пустых форм заказа.
* **Обработка дефектов:** Локализовала дефект верстки в разделе «Вопросы о важном» и зафиксировала его в баг-трекере проекта, сохранив изоляцию тестовой среды.

### 🚀 Инструкция по запуску проекта

### 1. Локальный запуск

pip install -r requirements.txt
pytest -v

### 2. Генерация и просмотр Allure-отчёта

pytest --alluredir=allure_results
allure generate allure_results -o allure-report --clean
allure open allure-repor

### 3. Запуск в CI/CD окружении

Пайплайн выполняется автоматически в облаке **GitHub Actions** при любом пуше или пулл-реквесте в ветку main.
